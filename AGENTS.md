# Project Rules & Guidelines

## Web UI & Problem Content Language Invariant
- **All Web UI Output in English**: All text rendered on the web frontend, including navigation items, buttons, modal dialogs, error toasts, and tooltips, must strictly be in English.
- **Problem Authoring & Starter Templates**:
  - Problem titles, descriptions, constraints, examples, and tags must be written in English.
  - Starter Java files (e.g. `Main.java`, domain classes) and inline comments (e.g. `// TODO: ...`) must strictly be in English.
- **Judge & Diagnostic Messages**:
  - Test case feedback, execution verdicts (e.g., `Accepted`, `Wrong Answer`, `OOP Violation`), and rule violation explanations must be presented in English.
- **Agent Responses vs Web Content**:
  - When the user asks questions in Vietnamese in the conversation, the agent may explain and converse in Vietnamese.
  - However, all artifacts, code, UI strings, and database seed content intended to be viewed on the web interface must remain strictly in English.
